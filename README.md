# Ziming Li

Personal academic website: [l-ziming.github.io](https://l-ziming.github.io/).

Built with Jekyll and the Academic Pages theme, hosted on GitHub Pages.

## Content

- `_pages/about.md` — homepage introduction
- `_pages/publications.html` — publications
- `_config.yml` — identity and site settings
- `_data/navigation.yml` — navigation
- `images/` — profile image and favicon assets

Updates to `master` publish through the existing GitHub Pages configuration.

The original theme's license is retained in [LICENSE](LICENSE).
